# Docs Index

This folder holds publishable product and platform references for the project.

## Files in this folder

- `style-guide.md`  
  Product and code style guide for Coding On The Go.
- `swiftui-references.md`  
  Apple SwiftUI and app-architecture references relevant to the client apps.
- `networking-apple-platform.md`  
  Apple platform notes for local network privacy, Network Extension, and App Store packaging implications.
- `macos-background.md`  
  macOS helper, login item, Service Management, notarization, and distribution notes.

## What belongs here

- Apple SwiftUI references
- Apple local-network and network-extension references
- macOS helper/background-task references
- the project style guide
- implementation conventions that tools and plugins can consume automatically

## What does not belong here

- competitor source copies
- ad hoc meeting notes
- throwaway debugging logs
- private secrets
