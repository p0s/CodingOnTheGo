# Coding On The Go Companion

This folder contains the real macOS companion target for Coding On The Go.

The companion app provides the host-side upgrade path for:

- presence publication and route-health reporting
- managed loopback listener lifecycle
- launch-at-login control
- capability scans
- notification bridge readiness reporting
- Codex Mac handoff helpers

The first successful connection still works without the companion. Once installed, the companion becomes the preferred enhanced path for reconnect, presence, and host-side lifecycle management.
